# Módulo 03 · Exercícios práticos

**Ex 1 — Ordenar três valores.** Escreva `void troca(int *a, int *b)`. Use-a para escrever `void ordena3(int *a, int *b, int *c)`, que deixa os três valores em ordem crescente. Leia três inteiros e mostre-os ordenados.

**Ex 2 — Quociente e resto.** Escreva `void divide(int a, int b, int *q, int *r)`. Leia dois inteiros e mostre quociente e resto (trate divisão por zero no `main`).

**Ex 3 — Estatísticas.** Escreva `void estatisticas(const int *v, int n, int *min, int *max, float *media)`. Leia `n` (até 100) e os `n` valores; mostre mínimo, máximo e média.

**Ex 4 — Busca com posição.** Escreva `int busca(const int *v, int n, int alvo, int *pos)`. Ela devolve 1 se achou (e grava a posição em `*pos`) ou 0 se não achou. Teste com um vetor fixo e vários alvos.
