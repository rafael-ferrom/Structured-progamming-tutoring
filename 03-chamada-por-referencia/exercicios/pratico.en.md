# Module 03 · Practical exercises

**Ex 1 — Sort three values.** Write `void troca(int *a, int *b)`. Use it to write `void ordena3(int *a, int *b, int *c)`, which leaves the three values in ascending order. Read three integers and print them sorted.

**Ex 2 — Quotient and remainder.** Write `void divide(int a, int b, int *q, int *r)`. Read two integers and print the quotient and remainder (handle division by zero in `main`).

**Ex 3 — Statistics.** Write `void estatisticas(const int *v, int n, int *min, int *max, float *media)`. Read `n` (up to 100) and the `n` values; print the minimum, maximum and average.

**Ex 4 — Search with position.** Write `int busca(const int *v, int n, int alvo, int *pos)`. It returns 1 if found (storing the position in `*pos`) or 0 if not found. Test with a fixed array and several targets.
