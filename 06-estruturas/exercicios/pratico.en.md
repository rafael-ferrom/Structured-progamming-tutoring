# Module 06 · Practical exercises

**Ex 1 — Rectangles.** Create `typedef struct { float largura, altura; } Retangulo;` and the functions `float area(Retangulo r)` and `float perimetro(Retangulo r)`. Create two rectangles and say which one has the larger area.

**Ex 2 — Report card.** Create `Aluno` (name, RA, grade1, grade2). Fill an array with 4 students, compute each one's average and print a table with the status (**Aprovado** if average ≥ 6, otherwise **Reprovado**).

**Ex 3 — Inventory.** Create `Produto` (code, name, price, stock). With an array of 5 products, find the **most expensive**, compute the **total stock value** (sum of price × quantity) and list the products with stock below 10.

**Ex 4 — Matrix of students.** Use `Aluno turmas[2][3]` (2 classes × 3 students, with two grades each). Compute each class's average and show the best student **among all** classes (name and class).
