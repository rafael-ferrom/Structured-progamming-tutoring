# Module 04 · Practical exercises

**Ex 1 — Your own string functions.** Implement using **pointers** (without calling `<string.h>`): `int meu_strlen(const char *s)`, `void meu_strcpy(char *dst, const char *src)` and `int meu_strcmp(const char *a, const char *b)`. Test with a few words and compare with the library functions.

**Ex 2 — Vowels and reversal.** Read a line with `fgets`. Print how many vowels it has, then reverse the string **in place** (using two pointers) and print it.

**Ex 3 — Palindrome.** Write `int eh_palindromo(const char *s)` that ignores upper/lower case and any character that is not a letter or digit. Test with `"Socorram-me, subi no onibus em Marrocos"` and `"Programacao"`.

**Ex 4 — Sort names.** Given an array of pointers with 6 names, sort them alphabetically by **swapping pointers** and print. Also print the longest name.
