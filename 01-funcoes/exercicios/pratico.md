# Módulo 01 · Exercícios práticos

**Ex 1 — Máximo de três.** Crie `int maximo(int a, int b, int c)` que devolve o maior dos três valores. No `main`, leia três inteiros e mostre o resultado.

**Ex 2 — Números primos.** Crie `int eh_primo(int n)` (devolve 1 se primo, 0 caso contrário). No `main`, imprima todos os primos de 1 a 50.

**Ex 3 — Fatorial.** Implemente o fatorial de duas formas: iterativa e recursiva. Leia `n` (0 a 20) e mostre os dois resultados para confirmar que são iguais.

**Ex 4 — MDC e MMC.** Crie `int mdc(int a, int b)` usando o algoritmo de Euclides e `int mmc(int a, int b)` usando o `mdc`. Leia dois inteiros positivos e mostre os dois resultados.

> Dica: compile com `gcc -Wall -Wextra -std=c11 arquivo.c -o programa` e leia todos os warnings.
