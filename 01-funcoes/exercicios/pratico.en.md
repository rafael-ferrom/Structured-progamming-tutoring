# Module 01 · Practical exercises

**Ex 1 — Maximum of three.** Create `int maximo(int a, int b, int c)` that returns the largest of the three values. In `main`, read three integers and print the result.

**Ex 2 — Prime numbers.** Create `int eh_primo(int n)` (returns 1 if prime, 0 otherwise). In `main`, print all primes from 1 to 50.

**Ex 3 — Factorial.** Implement the factorial in two ways: iterative and recursive. Read `n` (0 to 20) and print both results to confirm they are equal.

**Ex 4 — GCD and LCM.** Create `int mdc(int a, int b)` using Euclid's algorithm and `int mmc(int a, int b)` using `mdc`. Read two positive integers and print both results.

> Tip: compile with `gcc -Wall -Wextra -std=c11 file.c -o program` and read every warning.
