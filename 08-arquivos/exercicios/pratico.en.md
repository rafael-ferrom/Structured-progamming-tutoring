# Module 08 · Practical exercises

**Ex 1 — Sum of numbers.** Write the numbers 1 to 10 to the file `numeros.txt` (one per line). Then reopen the file, read all the values and print the sum and the average.

**Ex 2 — Copy a file.** Create `origem.txt` with a few lines. Copy its contents to `copia.txt` using `fgetc`/`fputc` and, during the copy, count characters and lines. Print the totals.

**Ex 3 — Number the lines.** Create a text file with 5 lines. Read it with `fgets` and print each line preceded by its number (`1: ...`). Also print the longest line.

**Ex 4 — Grades in a file.** Write to `notas.txt` the name (without spaces) and grade of 5 students in the format `name grade`. Then read the file with `fscanf`, print the class average and the student with the highest grade. Handle the case where the file doesn't exist.
