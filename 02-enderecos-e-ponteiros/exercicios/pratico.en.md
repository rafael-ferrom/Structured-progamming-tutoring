# Module 02 · Practical exercises

**Ex 1 — Basic pointers.** Declare an `int`, a `float` and a `char` with values. Create one pointer for each. Print the values and the addresses **using the pointers**. Then change the three values through the pointers and print the original variables.

**Ex 2 — Sum and reverse print.** Given the array `{4, 8, 15, 16, 23, 42}`, compute the sum and print the elements from last to first. **Use only pointers** (no `v[i]`).

**Ex 3 — Largest and smallest.** Given an integer array, find the largest and smallest elements using pointer arithmetic and also print the **index** of each (hint: subtract pointers).

**Ex 4 — Copy and reversal.** Copy an array `v` into another array `w` using only pointers. Then reverse `w` in place, using two pointers (one at the start and one at the end).
